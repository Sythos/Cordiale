# Cordiale 1.0.22

This release improves the Phoenix connection, unread message handling, and the safety of media and E2E data. It adds an unread divider and opens a channel at the first unread message.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* The channel view shows a temporary divider before the unread messages.
* The divider is hidden when the user pages with the keyboard.
* A channel opens at the first unread message.
* A channel badge lets the user visit the mentions.
* The unread placement ends when the pane follows the bottom.

### Fixes

* The client retries a rejected rejoin of a Phoenix topic.
* The client rejoins an active Phoenix topic after a Phoenix error.
* The client reconnects when a Phoenix heartbeat reply is missing.
* The WebSocket handshake has a deadline and shutdown handling.
* The client keeps one send task for each window and flushes the cursors on reconnect.
* The client retries a read-cursor update that is not confirmed after a failed POST.
* The client retries the channel history catch-up after a failure.
* The client rejects repeated Megolm messages.
* The radio stream stops its reads and decoder threads correctly.
* The MP4 parser limits the stsc sample mapping and rejects invalid run tables.
* The WebM parser decodes laced frames. It accepts all-ones EBML lace sizes.
* The E2E store recovers valid records after a truncated append.
* The client ignores stale E2E attachment results after the session ends or logout starts.
* The client ignores preference results from an earlier session.
* The personal preference Save action uses the loaded session.
* Each WHOIS avatar result is bound to its WHOIS view.
* The client ignores stale media link probes after logout or a newer open.
* Local settings changes use a locked update in the persistence layer. This keeps local settings during a server update.
* Clippy errors are fixed.

### Tests

* The tests cover the unread divider and keyboard paging.
* The tests cover the stsc run parsing.
* The tests cover stale E2E result handling with isolated temporary files.
* The tests cover the heartbeat reconnect.
