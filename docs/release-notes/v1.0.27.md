# Cordiale 1.0.27

This release adds channel invite links. It updates the client to protocol 67 and upgrades Slint to 1.19.0.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### Features

* The client opens channel invite links. The Home page has an Open invite action.
* The client selects the joined invite channel with the sidebar spelling.
* The client has translations for the channel invite texts.

### Protocol

* The client declares client protocol 67.
* The client reads member_modes for live mode events from protocol 66.

### Dependencies

* Upgrade Slint and slint-build to 1.19.0. Use Fontique 0.12.
* Update resvg to 0.49 to match the Slint 1.19.0 graph.
* Update qrcode to 0.15.0.
* Enable the arboard Wayland data control feature.

### Tests

* The tests cover the parser and flow decisions for channel invite links.
* The tests check that the QR code encodes the given URI.
* The tests cover the config parser for Grappa protocol 66 and 67.
* The live protocol check supports Grappa 66 and 67. It prints the server protocol values, names the target and prints a result line.

### Documentation

* The documentation describes channel invite links and the checked protocol versions.
* The protocol documents cover versions 66 and 67.
* The documentation describes the offline protocol 66 and 67 tests.
* The documentation lists the blocked duplicate dependencies, the windows-sys blocker and the Slint 1.19 findings.
