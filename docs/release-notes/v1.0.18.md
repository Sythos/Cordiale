# Cordiale 1.0.18

This release adds a command picker, command history in the Services console, and multi-line encrypted messages. It also shows client IP data in the WHOIS card and updates the audio player and dependencies.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* The Services console has a safe command history.
* A slash command picker shows command usage. The picker closes when the draft is not a command.
* The picker keeps the selected item in view when you move with the keys.
* Encrypted queries support messages with more than one line.
* The chat row shows the line breaks of decrypted messages.
* The WHOIS card shows client IP data when it is available.
* The admin credential editor has an auth method selector.
* The admin credential editor has a separate server pass field.

### Fixes

* The Services console history does not have a race condition. The history does not include group commands.
* The history keeps the draft when a pending Services send succeeds.
* The link icon does not count as a line in a multi-line chat row.
* Cordiale builds the credential model rows on the UI thread.
* Clippy errors in the multi-line chat row code are fixed.
* The audio player drops frames before the seek target.

### Dependencies

* The audio player uses Symphonia 0.6.
* Updated Cargo dependencies include avif-parse, rfd, resvg, rusty_vp9 and sysinfo.
* Updated GitHub Actions include taiki-e/install-action and softprops/action-gh-release.
* The lockfile has updated compatible transitive dependencies.
* The project records the Cargo dependency updates that are blocked.

### Documentation

* The documentation describes the auth method change in the credential editor.

### Tests

* The tests cover the multi-line E2E round trip in the engine.
* The tests cover the line breaks of a received multi-line row.
* The tests check that WHOIS client IP rows do not change other card rows.
* The tests cover FLAC and MP3 playback in the audio player.
