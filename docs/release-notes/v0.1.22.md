Cordiale package version: `${PACKAGE_VERSION}` (tag version `${VERSION}`, GitHub Actions run ID `${RUN_ID}`, attempt `${RUN_ATTEMPT}`).

Where four numeric components are supported, the fourth is the GitHub Actions run ID. Windows VERSIONINFO stores its reduction below 65535 in the numeric component and preserves the full ID in string metadata. macOS keeps the tag in `CFBundleShortVersionString`, uses a valid compact `CFBundleVersion`, and records the full run ID in `CordialeBuildID` and `CordialeBuildVersion`.

Tester note: Cordiale handles all currently inventoried Grappa event kinds. Only message events are rendered as chat lines; see the README for behavior and current limitations.

Heads up: every package here is unsigned, on every platform. No code-signing certificate is used, even though the filenames do not say so. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned, community-built app. It does not mean that someone changed the package. Each artifact includes a SHA256SUMS file and a build provenance attestation, so you can verify it yourself. See [docs/installation.md](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md).

## Highlights
This release hardens file, media and radio stream handling. It also changes the sidebar, channel name checks and commands. It updates dependencies.

* **Stream guard refuses local targets.** Cordiale refuses local targets for radio streams and playlist entries. The guard also rejects multicast and reserved addresses. It rejects IPv6 site-local, benchmarking and documentation prefixes. It rejects the local-use NAT64 prefix.
* **Temporary media files are private.** Cordiale creates temporary media files in a private folder. It discards the temporary files of stale media and wallpaper downloads. Video uploads use secure temporary files and a queue limit.
* **Authenticated file downloads have a size limit.** Cordiale limits the size of authenticated file downloads.
* **Uploads run in a task that you can cancel.** Cordiale reads upload files only after an upload slot is free. It keeps the upload slot until the blocking read ends. Uploads can start locally on the Grappa server.
* **Upload lifetime label rounds up.** Cordiale rounds the upload lifetime label up to the next whole hour.
* **Prefix-only channel names are rejected.** Cordiale rejects prefix-only channel names in join and history. It ignores them in joined, failed and kicked events.
* **Command aliases have new items.** Cordiale adds the `$C` target placeholder and the built-in `onotice` alias.
* **Unread badge stays current.** Cordiale refreshes the unread badge after a read cursor update.
* **Sidebar and member column have drag limits.** The drag width keeps the chat usable. The member column limit uses the current sidebar width and the window width.
* **Sidebar scrollbar has its own space.** Cordiale reserves a right gutter for the sidebar scrollbar.
