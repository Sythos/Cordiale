## 👉 Pick the right file first

You need exactly **one** installer or package for your machine:

| You're on | Grab this |
|---|---|
| Windows, regular PC (Intel/AMD) | `Cordiale_Windows_x64.exe` |
| Windows on ARM (Surface, Snapdragon laptops) | `Cordiale_Windows_arm64.exe` |
| macOS, Apple Silicon | `Cordiale_macOS_arm64.dmg` |
| macOS, Intel | `Cordiale_macOS_x64.dmg` |
| Debian 13 | `Cordiale_Debian_13_amd64.deb` (or `_arm64.deb`) |
| Ubuntu 26.04 | `Cordiale_Ubuntu_26.04_amd64.deb` (or `_arm64.deb`) |
| AlmaLinux 10 / RHEL-ish | `Cordiale_AlmaLinux_10_x86_64.rpm` (or `_aarch64.rpm`) |
| Arch Linux | `Cordiale_Arch_rolling_x86_64.pkg.tar.zst` (or `_aarch64`) |
| Another Linux distro | `cordiale-linux-amd64-${PACKAGE_VERSION}.tar.gz` (or `arm64`) |

The `.zip` / `.tar.gz` files are bare binaries. `Cordiale_src.tar.gz` is the source archive; `SHA256SUMS-*` lets you check the downloads. Installation and unsigned-app help: [docs/installation.md](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md).

## New since 0.1.12

This beta makes two everyday things a little less fussy: older chat arrives as you scroll, and Cordiale can tell you when a newer release is ready.

- **Keep scrolling, keep reading.** Reach the oldest loaded line in a channel and Cordiale asks Grappa for the preceding page automatically. Your place in the conversation stays put while those older messages arrive; loading stops at the beginning of history, and the manual **Load older messages** button remains as a fallback. No more clicking your way through yesterday. ([#125](https://github.com/Sythos/Cordiale/issues/125))
- **A heads-up for new releases.** On startup, Cordiale checks the latest release in the background. If its major, minor or patch version is newer, a small popup shows both versions and opens the [latest release](https://github.com/Sythos/Cordiale/releases/latest) in your system browser when you choose to visit. A packaging build ID on its own does not trigger an update, and a failed check never delays sign-in. ([#127](https://github.com/Sythos/Cordiale/issues/127))

The radio still plays **MP3, Ogg Vorbis and FLAC** streams on every target, including custom stations, and `/np` still shares the current track.

Cordiale handles the currently inventoried Grappa realtime event kinds; only message events become chat lines. The remaining known gaps and platform limits are in the [README](https://github.com/Sythos/Cordiale#known-gaps).

## Build and verification

Package version: `${PACKAGE_VERSION}` (tag `v${VERSION}`, build/run ID `${BUILD_ID}`, attempt `${BUILD_ATTEMPT}`). All six platform builds and the source archive completed before this release was published. CI on the tagged commit passed on Linux and Windows, and CodeQL passed for Rust and Actions. Where a fourth numeric version component is supported, it derives from the run ID; Windows stores the reduced 16-bit value in VERSIONINFO and preserves the full ID in string metadata, while macOS records the full ID in its bundle metadata.

Every package is **unsigned**. SmartScreen, Gatekeeper or a package manager may grumble; use the checksums and build provenance attestations if you want to verify it yourself. The binary and packaging icons are included where those platforms support them.
