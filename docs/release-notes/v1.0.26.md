# Cordiale 1.0.26

This release fixes the unread count and the emoji picker. It updates the client to protocol 65.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### Fixes

* The client clears the unread count when the last unread row is visible.
* The client includes a monochrome emoji font as the last fallback font. The emoji picker no longer shows square boxes for some emoji.
* The client accepts E2E file records that have no sha256 value.
* The file copy format for E2E attachments is correct.
* The client shows that a guest nickname is not available on the network.
* The client keeps the error code of read-cursor requests.
* The client stops read-cursor retries for closed queries.

### Protocol

* The client declares client protocol 65.

### Dependencies

* Update url to 2.5.9. This fixes RUSTSEC-2026-0592.
* Update zeroize to 1.9.2, vp8-decoder to 0.1.2, and sysinfo to 0.40.4.
* Update taiki-e/install-action to 2.90.5.

### Tests

* The tests cover the unread hold guard and the placement test.
* The tests cover the emoji fallback font without system fonts.
* The malformed file descriptor test accepts an optional sha256 value.

### Documentation

* The documentation describes the emoji fallback font.
* The documentation describes protocol 65 and the read-cursor contract.
* The README includes the OpenMoji credit.
