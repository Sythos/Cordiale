# Cordiale 1.0.10

This release adds end-to-end encrypted file attachments and end-to-end encryption for channel messages. It adds per-channel input history to the chat composer. It keeps the chat position when the user switches the ciphertext view.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* Cordiale encrypts file attachments end to end.
* Cordiale removes metadata from images before it encrypts them.
* Cordiale sends and opens encrypted files in locked query windows.
* Cordiale sends and copies file descriptors through the E2E engine.
* Cordiale adds encrypted upload and download routes to the client.
* Cordiale encrypts channel messages end to end.
* Cordiale removes revoked devices from E2E channels and rotates the session.
* The chat composer keeps a separate input history for each channel.

### Fixes

* Cordiale cleans every JPEG scan and removes the data after the end marker.
* Cordiale refuses cross-origin redirects in encrypted file downloads.
* Cordiale saves large encrypted text files through the save dialog.
* Channel sends stay pending until all members have the key.
* Cordiale reads channel messages from the stored state after a restart.
* The chat keeps its position when the user switches the ciphertext view.
* The chat drops the row offset when the ciphertext view switches.
* Cordiale clears the input history when the user disconnects.
* The composer keeps the pending reply when the input history recalls a draft.
* A fix gives correct access to the private E2E reset state.

### Dependencies

* The AES-GCM crate is added for encrypted file attachments.

### Documentation

* The documents describe encrypted file attachments.
* The documents describe channel revocation and the single key write.
