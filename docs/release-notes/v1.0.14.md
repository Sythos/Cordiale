# Cordiale 1.0.14

This release adds text selection in chat rows and more media formats in the media player. It also adds E2E request alerts and a link picker in the chat row menu.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* You can select and copy text in chat rows with the mouse or the keyboard.
* You can select chat rows that have links, bold text and plain text.
* A drag in the chat selects a nickname or a range of rows.
* The chat row menu has a link picker for rows with many links.
* The media player plays H.264, VP8 and AV1 video and Vorbis sound.
* The media viewer shows AVIF images.
* Cordiale alerts you about incoming E2E requests.
* Cordiale shows pairing recovery for accepted E2E requests.
* Cordiale links URLs inside low-high quote pairs.
* The admin and settings views show detected source addresses and selection of the vhost.

### Fixes

* Cordiale keeps the file type from Content-Disposition when it opens media.
* The media player reopens ended audio when you seek.
* Cordiale keeps the AV1 color range and identity matrix in video playback.
* Closing the media viewer keeps the chat state.
* Cordiale keeps request marks across sync and refreshes the sidebar when a request is removed.
* Cordiale includes E2E request attention in the followed query counts.
* The code uses `as_chunks` and `is_empty` to satisfy newer clippy lints.

### Documentation

* The README describes in-place chat selection, rows with links and rows with mixed weights.
* The docs describe the supported media formats.
* The docs describe the admin vhost response fields.
