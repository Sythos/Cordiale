# Cordiale 1.0.9

This release adds progress rows for incoming E2E messages and the added time of E2E devices. It limits new device enrollment to three devices. It updates the app icon and dependencies.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* Cordiale has a new app icon.
* Cordiale shows progress rows for incoming E2E messages that have more than one frame.
* The E2E view shows the time when each device was added.
* Cordiale parses and routes the e2e_incoming events.
* New device enrollment is limited to three devices.

### Fixes

* Cordiale hides stale E2E request prompts after the key comparison.
* Cordiale clears the E2E progress rows when the session ends.
* Cordiale sends the signed list after a message for a missing device.
* The lock file update clears the RustSec findings.
* The vodozemac and unicode-width requirements are updated.
* The taiki-e/install-action workflow dependency is updated to version 2.90.0.

### Documentation and tests

* The documents describe the protocol 59 incoming events.
* The documents describe that Cordiale clears the E2E progress rows when the session ends.
* A new test checks that the device list keeps devices with any added time.
* A fix for the device list test makes the test compile.
