## 👉 Pick the right file first

You need exactly **one** installer or package for your machine:

| You're on | Grab this |
|---|---|
| Windows, regular PC (Intel/AMD) | `Cordiale_Windows_x64.exe` |
| Windows on ARM (Surface, Snapdragon laptops) | `Cordiale_Windows_arm64.exe` |
| macOS, Apple Silicon | `Cordiale_macOS_arm64.dmg` |
| macOS, Intel | `Cordiale_macOS_x64.dmg` |
| Debian 13 | `Cordiale_Debian_13_amd64.deb` (or `_arm64.deb`) |
| Ubuntu 26.04 | `Cordiale_Ubuntu_26.04_amd64.deb` (or `_arm64.deb`) |
| AlmaLinux 10 / RHEL-ish | `Cordiale_AlmaLinux_10_x86_64.rpm` (or `_aarch64.rpm`) |
| Arch Linux | `Cordiale_Arch_rolling_x86_64.pkg.tar.zst` (or `_aarch64`) |
| Another Linux distro | `cordiale-linux-amd64-${PACKAGE_VERSION}.tar.gz` (or `arm64`) |

The `.zip` / `.tar.gz` files are bare binaries. `Cordiale_src.tar.gz` is the source archive; `SHA256SUMS-*` lets you check the downloads. Installation and unsigned-app help: [docs/installation.md](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md).

## New since 0.1.15

This release is about keeping your place, knowing who you're talking to and being able to read it all. Cordiale remains a native Rust + Slint app, with no browser engine stowed away in the suitcase.

### Reading and chat

- **Your place in the scrollback stays put.** Scroll up in a long channel, open an image, a link, Settings, the archive, a WHOIS card or the radio, come back, and you're on the same line instead of being yanked to the newest message. If you were reading at the bottom, you still land at the bottom. Restoring the line can be off by about a row when you're very close to the top of the history, and a history page that lands while you're away can nudge it by one. ([#188](https://github.com/Sythos/Cordiale/issues/188), [PR #194](https://github.com/Sythos/Cordiale/pull/194))
- **Kicked rows don't pull a vanishing act.** A kicked, failed, pending or invited channel row used to disappear a moment after it showed up, whenever the channel list refreshed. Now it stays, with its details, until you dismiss it. Network refreshes also stop wiping that state on the networks that stay. ([#184](https://github.com/Sythos/Cordiale/issues/184), [PR #191](https://github.com/Sythos/Cordiale/pull/191))

### DMs and nick changes

- **Mentions know who whispered.** An inbound DM in the mentions summary is now labelled with the peer instead of with your own nick, using the `dm_with` field from Grappa's protocol 35. Older servers behave as before. This is tested against simulated data, not yet a live server. ([#183](https://github.com/Sythos/Cordiale/issues/183), [PR #189](https://github.com/Sythos/Cordiale/pull/189))
- **A nick change no longer shuffles your windows.** Cordiale now follows Grappa protocol 37: a nick change, yours or a peer's, renames and moves nothing on the server. When a peer changes nick, their next message opens a new window under the new name, and the old window keeps its history. Mutes, read positions and drafts are not carried over to the new one. Cordiale now declares `client_proto=37`, and Grappa rows carry `dm_with` to tell DMs apart. The old rename-guessing stays only for servers below 37. This is only fully live once the Grappa server you use runs protocol 37. ([#195](https://github.com/Sythos/Cordiale/issues/195), [PR #196](https://github.com/Sythos/Cordiale/pull/196))

### Member list and commands

- **Roles follow your network, not a hard-coded list.** The member list takes role symbols, order and the moderation menu from the network's `PREFIX` instead of a fixed `~&@%+`. On the usual networks nothing changes; on one with an extra level or a missing one, ranks and menus now match what the server says. Not yet tried on a live network with an extra symbol. ([#186](https://github.com/Sythos/Cordiale/issues/186), [PR #192](https://github.com/Sythos/Cordiale/pull/192))
- **`/msg @#chan` and `/msg +#chan` reach the right crowd.** Messages to a channel's ops or voiced users go through Grappa's STATUSMSG door, with no stray query window opened. Plain `#chan` and bare `+chan` targets are still refused. ([#185](https://github.com/Sythos/Cordiale/issues/185), [PR #190](https://github.com/Sythos/Cordiale/pull/190))

### Colours

- **Secondary text you can actually read.** Muted text, timestamps, directory labels, error text and the muted colours of the colour themes now meet the WCAG AA 4.5:1 contrast ratio, in classic dark and light and in the gallery themes. Colours that already passed are left alone. ([#187](https://github.com/Sythos/Cordiale/issues/187), [PR #193](https://github.com/Sythos/Cordiale/pull/193))

The radio still plays **MP3, Ogg Vorbis and FLAC** on every target, including custom stations. The remaining known gaps and platform limits are in the [README](https://github.com/Sythos/Cordiale#known-gaps).

And yes: if I find another missing feature ten minutes after publishing this release, I'll wait for the *next* release. Probably. :)

## Build and verification

Package version: `${PACKAGE_VERSION}` (tag `v${VERSION}`, build/run ID `${BUILD_ID}`, attempt `${BUILD_ATTEMPT}`). All six platform builds and the source archive completed before this release was published. CI on the tagged commit passed on Linux and Windows, and CodeQL passed for Rust and Actions. Where a fourth numeric version component is supported, it derives from the run ID; Windows stores the reduced 16-bit value in VERSIONINFO and preserves the full ID in string metadata, while macOS records the full ID in its bundle metadata.

Every package is **unsigned**. SmartScreen, Gatekeeper or a package manager may grumble; use the checksums and build provenance attestations if you want to verify it yourself. The binary and packaging icons are included where those platforms support them.
