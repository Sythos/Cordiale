## 👉 Pick the right file first

You need exactly **one** installer or package for your machine:

| You're on | Grab this |
|---|---|
| Windows, regular PC (Intel/AMD) | `Cordiale_Windows_x64.exe` |
| Windows on ARM (Surface, Snapdragon laptops) | `Cordiale_Windows_arm64.exe` |
| macOS, Apple Silicon | `Cordiale_macOS_arm64.dmg` |
| macOS, Intel | `Cordiale_macOS_x64.dmg` |
| Debian 13 | `Cordiale_Debian_13_amd64.deb` (or `_arm64.deb`) |
| Ubuntu 26.04 | `Cordiale_Ubuntu_26.04_amd64.deb` (or `_arm64.deb`) |
| AlmaLinux 10 / RHEL-ish | `Cordiale_AlmaLinux_10_x86_64.rpm` (or `_aarch64.rpm`) |
| Arch Linux | `Cordiale_Arch_rolling_x86_64.pkg.tar.zst` (or `_aarch64`) |
| Another Linux distro | `cordiale-linux-amd64-${PACKAGE_VERSION}.tar.gz` (or `arm64`) |

The `.zip` / `.tar.gz` files are bare binaries. `Cordiale_src.tar.gz` is the source archive; `SHA256SUMS-*` lets you check the downloads. Installation and unsigned-app help: [docs/installation.md](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md).

## New since 0.1.13

This one is a proper step forward: account access, reconnects, profile settings and admin tools all got real attention. Cordiale is catching up with Cicchetto while staying a native Rust + Slint app — no browser engine has snuck into the luggage.

- **Passkeys come to Windows.** Use Windows Hello, a security key or a phone for Grappa's WebAuthn ceremony: finish sign-in as a second factor, sign in without a password, add a passkey and change passkey mode in Settings > Security. Recovery-code sign-in is available from the connect screen for passwordless accounts too. Cordiale also lists your passkeys and lets a full-session user remove one with their password. This follows Grappa's protocol and mock-server tests, but the ceremonies have **not yet been tried with a real authenticator or live Grappa instance**. ([#147](https://github.com/Sythos/Cordiale/issues/147), [#160](https://github.com/Sythos/Cordiale/issues/160))
- **Hand a session to another device.** Settings > Security can create a single-use share link and QR code, valid for ten minutes; the connect screen can consume a link or token made by Cordiale or Cicchetto. Useful when your other device is already signed in and you would rather not juggle another login. The flow is tested against a simulated server, not yet a live one. ([#156](https://github.com/Sythos/Cordiale/pull/156))
- **A reconnect no longer means a silent hole in chat.** Cordiale checks each channel for messages missed while the WebSocket was away. Small gaps are fetched in order; for a large gap it reloads the newest messages and tells you what happened. It declares `client_proto=34` on the WebSocket upgrade and stops with an update prompt if Grappa rejects the client version, instead of retrying forever. A peer changing nick now keeps the same DM window where Grappa supplies its conversation ID. ([#153](https://github.com/Sythos/Cordiale/pull/153), [#149](https://github.com/Sythos/Cordiale/pull/149), [#148](https://github.com/Sythos/Cordiale/pull/148))
- **Presence and invitations behave more like the web client.** Cordiale tells Grappa when the window is in the foreground, so auto-away and push-notification decisions have the right signal. It reports an orderly close, and a channel invite now offers both **Join** and **Decline**. ([#154](https://github.com/Sythos/Cordiale/pull/154), [#150](https://github.com/Sythos/Cordiale/pull/150))
- **Your profile is yours to edit.** Settings > General now edits your per-network CTCP USERINFO fields and uploads or removes your avatar. The admin console also gains the missing day-to-day operations: session controls, featured channels, server and credential edits, plus a network-deletion confirmation that states the scrollback impact when Grappa can report it. ([#155](https://github.com/Sythos/Cordiale/pull/155), [#157](https://github.com/Sythos/Cordiale/pull/157))
- **A useful Debug page, without a data upload.** Copy system and build details into a bug report from the new Debug view. It leaves out account names, server addresses, tokens and user names in paths; unavailable platform details are labeled honestly. ([#158](https://github.com/Sythos/Cordiale/pull/158))

### A candid platform note

Windows passkey ceremonies are included in these installers. USB security-key ceremonies for Linux and macOS are implemented behind the optional `ctap-hid` Cargo feature, but **that feature is off in the release packages** until it has its own CI build and hardware testing. The passkey, sharing and newer Grappa flows above have source-backed tests with a simulated server; please treat first use against a real instance as beta testing, not a promise that every authenticator has already been tried.

The radio still plays **MP3, Ogg Vorbis and FLAC** on every target, including custom stations. The remaining known gaps and platform limits are in the [README](https://github.com/Sythos/Cordiale#known-gaps).

## Build and verification

Package version: `${PACKAGE_VERSION}` (tag `v${VERSION}`, build/run ID `${BUILD_ID}`, attempt `${BUILD_ATTEMPT}`). All six platform builds and the source archive completed before this release was published. CI on the tagged commit passed on Linux and Windows, and CodeQL passed for Rust and Actions. Where a fourth numeric version component is supported, it derives from the run ID; Windows stores the reduced 16-bit value in VERSIONINFO and preserves the full ID in string metadata, while macOS records the full ID in its bundle metadata.

Every package is **unsigned**. SmartScreen, Gatekeeper or a package manager may grumble; use the checksums and build provenance attestations if you want to verify it yourself. The binary and packaging icons are included where those platforms support them.
