# Cordiale 1.0.12

This release adds end-to-end encryption (E2E) keys for channels. It also fixes the Radio and Admin settings panels and the start of private E2E queries.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* The core refills one-time keys (OTK).
* The core copies channel keys between sibling devices.
* The client uses channel membership and channel keys.

### Fixes

* The Radio and Admin settings content stays at the top of the panel.
* Cordiale reports the real cause when a private E2E query cannot start.
* Cordiale blocks consent actions until provisioning ends with success.
* Cordiale keeps channel sequence numbers.
* Cordiale retries failed channel key requests.
* Cordiale keeps saved channel members while it discovers their devices again.
* Cordiale rotates the start of channel key discovery across the roster.
* Cordiale keeps saved channel devices only for nicks that wait for keys.
* Cordiale matches saved channel devices with the nick casemapping.

### Documentation

* The documents describe E2E channels and the OTK refill.
