# Cordiale 1.0.19

This release adds multi-line messages in encrypted chat and shows client IP data in the WHOIS card. It also adds a separate server pass field, moves the audio player to Symphonia 0.6, and fixes sidebar fit and compose field focus.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* Encrypted chat supports multi-line messages.
* The WHOIS card shows the client IP data when it is available.
* The admin credential form has a separate server pass field.
* The audio player uses Symphonia 0.6.
* The audio player drops frames before the seek target.

### Fixes

* The link icon is not counted in the line count of a multi-line row.
* The command picker closes when the draft is not a command.
* The history draft stays when a pending Services send succeeds.
* Cordiale builds the credential model rows on the UI thread.
* The sidebar fits its widest row. The sidebar limit is 720 px.
* Cordiale measures every sidebar row to fit the sidebar width.
* The compose field uses LineEdit in every window. This restores mouse focus in the channel message field.
* Clippy errors in the multi-line chat row code are fixed.

### Dependencies

* Updated: avif-parse, rfd, resvg, rusty_vp9, sysinfo and symphonia.
* Updated: the compatible transitive dependencies in the lockfile.
* Updated: the GitHub Actions taiki-e/install-action and softprops/action-gh-release.
* Cordiale records the Cargo dependency updates that are blocked.

### Tests

* The tests cover the multi-line E2E round trip in the engine.
* The tests cover the line breaks of a received multi-line row.
* The tests cover the WHOIS client IP rows and the other card rows.
* The tests cover FLAC and MP3 playback in the audio player.
* The tests cover mouse focus, paste and send in the compose field.
* The tests cover the sidebar width fit, the 720 px limit and a narrow window.
