Cordiale package version: `${PACKAGE_VERSION}` (tag version `${VERSION}`, GitHub Actions run ID `${RUN_ID}`, attempt `${RUN_ATTEMPT}`).

Where four numeric components are supported, the fourth is the GitHub Actions run ID. Windows VERSIONINFO stores its reduction below 65535 in the numeric component and preserves the full ID in string metadata. macOS keeps the tag in `CFBundleShortVersionString`, uses a valid compact `CFBundleVersion`, and records the full run ID in `CordialeBuildID` and `CordialeBuildVersion`.

Tester note: Cordiale handles all currently inventoried Grappa event kinds. Only message events are rendered as chat lines; see the README for behavior and current limitations.

Heads up: every package here is unsigned, on every platform — no code-signing cert anywhere, even though the filenames don't say so. Windows SmartScreen and some Linux package managers might complain about it; that's expected for an unsigned, community-built app, not a sign of tampering. Each artifact still ships a SHA256SUMS file and a build provenance attestation if you want to verify it yourself — see [docs/installation.md](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md).

## Highlights
A small but careful release, mostly about admin tools that now say "are you sure?" and "here's what went wrong" instead of shrugging.

* **Network delete thinks twice.** In the admin area, deleting a network is blocked until the scrollback count is known. If Cordiale doesn't know how much history is at stake, it won't let you press the big red button. Look before you leap.
* **Visitor delete failures get a voice.** When deleting a visitor fails, you now see the error instead of a silent refresh that left you wondering whether anything happened. Bad news, but at least it's honest news.
* **Ban type stays in sync.** The default ban type now follows Grappa's ban-mask-form setting, so your bans start out the way the server expects. One less dropdown to second-guess.
