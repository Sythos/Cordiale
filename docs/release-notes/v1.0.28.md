# Cordiale 1.0.28

This release updates the client to protocol 68. It adds a reconnect request before JOIN and improves refusal messages. It also corrects problems and updates dependencies.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### Features

* The client asks you to reconnect before JOIN when this is necessary.
* The client shows a message for each Grappa invite attach refusal.
* The Home page shows the reason for an attach refusal.
* The client explains when a network is full during guest sign-in.

### Fixes

* The client keeps each accepted reconnect and JOIN on the same network.
* The client ignores reconnect results from a detached network.
* The client applies watchlist changes only after the server replies.
* Unanswered host lookups for ban and kickban now expire.

### Protocol

* The client declares Grappa protocol 68.
* The client core supports `not_registered` and reconnect before JOIN.
* The reconnect before JOIN matches the Grappa 68 source.

### Dependencies

* Update resvg from 0.49.0 to 0.50.0.
* Update rusty_vp9 from 0.2.1 to 0.3.0.
* Update vp8-decoder from 0.1.2 to 0.1.3.
* Update rusty_h265 from 0.7.1 to 0.7.2.
* Update rusty_h264-decoder from 0.17.2 to 0.17.4.
* Update taiki-e/install-action from 2.90.5 to 2.90.8.

### Documentation

* The documentation describes the protocol 68 behavior and the checked Grappa 68 contract.
* The documentation describes the attach refusal messages of the Home page.
* The protocol notes describe the watchlist reply contract.
* The Cordiale protocol status note is up to date.
