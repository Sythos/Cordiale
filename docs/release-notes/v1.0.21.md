# Cordiale 1.0.21

This release adds emoji search and an emoji picker in the composer. It also adds date separators in the channel transcript and optional hardware video decoding. It improves startup, audio and video playback, and the layout of the bottom rows.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* The composer has emoji suggestions and an emoji picker.
* The composer supports emoji search and shortcode text edits.
* The channel transcript shows date separator rows between days.
* The player can use optional hardware video decoding. It uses software decoding if the hardware decoder fails.
* The Windows x64, Windows ARM64 and macOS packages include hardware decoding.
* The player measures audio under-runs and late video frames.
* The splash screen starts the launch sign-in when it hands off.

### Fixes

* The audio worker keeps the first decoded audio packet.
* The player keeps the queued pictures when the hardware decoder falls back to software decoding.
* The player sends AV1 configuration OBUs to the hardware decoder.
* The date separator rows are counted in the mention rows and the locked-view rows.
* The bottom compose row and the Actions row stay at the bottom.
* The Channels button and the channel list are aligned.
* The Windows hardware decoding link is fixed.
* Clippy errors in the hardware decode code are fixed.

### Dependencies

* Added: the emojis crate for emoji data.
* Added: the static FFmpeg feature for macOS hardware decoding.
* Updated: the dependency files for hardware video decoding.
* The Intel macOS FFmpeg build installs nasm.

### Tests

* The tests cover emoji search and shortcode text edits.
* The tests cover the compose row and the Actions row at the bottom.
* The tests cover the sidebar layout scan position and column fitting.
* The tests cover the splash handoff window size.
* The tests cover the anchor line after the spacer marker.

### Documentation

* The documentation describes playback measurements and platform checks.
* The documentation describes tester builds, release gating and the results log.
* The documentation describes the field test steps and the hardware decoding release gate.
* The documentation records the linking choice for hardware decoding packages.
* A manual check list covers the compose row and the Actions row.
