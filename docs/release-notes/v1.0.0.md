# Cordiale 1.0.0

Cordiale is now a stable release. This release ends the beta period. It includes the product work from versions 0.1.5 to 0.1.22, plus the changes that entered `main` after version 0.1.22.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### IRC and chat

* Cordiale supports all event kinds in the current Grappa protocol inventory. It renders message events as chat lines. Other event kinds update connection, channel, user, history and administration state.
* The home view shows connected, parked and failed networks. It also shows featured channels and networks that you can join. A server window shows connection messages, the message of the day and service replies.
* Open the channel directory from the sidebar or with `/list`. Search and refresh the directory, read channel topics and member counts, and join a channel from its row.
* Use `/join` from the server window. Commands that need a channel or private chat now explain where they work.
* Cordiale keeps guest sign-in state separate from account sign-in. It uses the nickname that you enter, explains common sign-in failures and lets a guest return to the same session.
* The member list reads role symbols and order from the network's `PREFIX` value. It shows operator, half-operator and voice roles. Moderation menus use the same network settings.
* Channel invitations offer Join and Decline. Pending, invited, failed and kicked channel rows keep their state until you dismiss them.
* `/msg @#channel` and `/msg +#channel` use Grappa's `STATUSMSG` support. Cordiale also supports `/me`, `/query`, `/part`, `/topic`, `/away`, moderation commands, service shortcuts and command aliases. The `$C` alias target and built-in `onotice` alias are available.
* Reply quotes the selected message. It uses the current nick spelling, follows a nick change, warns when the quoted author left and preserves the text that you type while the quote loads. It removes reply context when the author leaves or is kicked. Replayed presence events do not change reply state.
* Direct-message windows keep their send target when a peer changes nick. Cordiale pages folded windows apart and reloads them when a link ends.
* Tab completes nicknames from the member list. It can cycle through matching names. Private chats complete the other person's nickname.
* The channel Actions menu can hide routine join, part, quit, nick and mode notices. Grappa keeps member state current while these notices are hidden. The choice is saved for each channel.
* Mentions show the correct sender for direct messages. A warning appears when the mentions summary is incomplete.
* Cordiale follows Grappa protocol version 37 for nick changes and direct messages. A peer's new nick opens a new direct-message window. The old window keeps its history. Older protocol versions keep the compatible rename behavior.
* Reconnect uses backoff, jitter and the server's `Retry-After` value. Cordiale checks for missed channel messages and loads missing history after a short network loss. It asks for a client update if the server does not accept the protocol version.
* Scrolling to the start of loaded history loads older messages. Cordiale keeps your scroll position when you open another view and return. Direct-message history does not use an arbitrary client-side cap.
* Message rows show mIRC colours and wide text without sideways panning. Long channel topics wrap. Unread counts update when you read a channel or change the read cursor. The active channel stays visible in the sidebar.
* Cordiale shows the connection destination, user modes, channel and channel modes in the chat header.

### Account security and privacy

* A full password session can enable or disable TOTP in Settings > Security. Sign-in supports authenticator codes and one-time recovery codes. Cordiale shows new recovery codes once. Client tokens cannot manage account security.
* Windows supports passkeys through WebAuthn, including Windows Hello, security keys and phones. Full-session users can add, list and remove passkeys. Recovery-code sign-in is available for passwordless accounts.
* Settings > Security can create a single-use session link and QR code. The link expires after ten minutes. Cordiale can use a link or token from Cordiale or Cicchetto.
* Password sign-in over plain HTTP shows a warning before credentials leave the client. HTTPS is preferred. REST and WebSocket connections use the same platform trust roots.
* External links are checked before Cordiale opens them. Cordiale checks image and media redirects before each request. Radio streams and playlist entries cannot use local, multicast, reserved or other blocked network addresses.
* Cordiale writes settings and credential files through a private, atomic replacement path. It moves older configuration to the platform data folder and rotates logs with a size limit. Automatic sign-in uses the operating system keyring.
* Debug information can be copied for a bug report. It does not include account names, server addresses, tokens or user names in file paths.

### Uploads, media and radio

* Send files with the attachment button, drag and drop, or paste. Cordiale previews an upload and lets you choose its lifetime before it sends. It adds the remaining lifetime to the shared link.
* Cordiale can shrink a video before upload. You can turn this off for each upload. Upload work uses a queue and can be cancelled. A local server can start an upload without blocking session events.
* Temporary media files use a private folder. Cordiale removes stale media and wallpaper files. Authenticated downloads have a size limit. Upload lifetime labels round up to the next whole hour.
* Sending a file does not add a permanent status message to the chat. Cordiale writes the event to its log.
* Images and other media links open in a popup over the conversation.
* The radio player supports MP3, Ogg Vorbis and FLAC. Add custom stations, play audio links and use `/np` to show the current track. The station list opens in a compact panel.

### Settings, themes and administration

* The theme gallery supports Grappa themes, built-in theme copies, light and dark variants, system day and night settings, wallpapers, role colours and a theme editor for colours, fonts, publish, copy and delete actions.
* Settings can change the date format and app text size. The text size range is 50% to 150%, with a reset action and keyboard support. Settings also support wildcard text filters for ignored messages and a server-managed away nickname suffix.
* Notifications support mentions, channel and nick rules, timed or permanent mute, `/beep` sounds and a Windows taskbar unread badge.
* Navigation buttons show their names on hover and keyboard focus.
* Settings > General can edit per-network CTCP USERINFO fields and upload or remove an avatar.
* The admin console manages accounts, passwords, sessions, featured channels, networks, servers, credentials, visitor and account vhosts, server settings, uploads and the live admin feed. It shows the upload budget and active and historical uploads. It can delete active uploads and shows the scrollback count before it deletes a network when Grappa provides that count.
* Cordiale shows errors when visitor deletion fails. The default ban type follows the server account setting. The moderation menus include explicit nick and host bans, kick-ban and the selected ban type. Translated ban labels keep IRC mask examples unchanged.
* The UI adds a Services console and centers status notices. The left sidebar stays wide enough for its buttons. Its scrollbar does not cover the buttons. Sidebar and member-panel resizing keep the chat usable.
* The Windows uninstaller uses the default icon and does not add an uninstaller shortcut to the Start menu.
* Cordiale rejects channel names that contain only a status prefix. It shows a specific translated error for an invalid channel name.

### Platforms and maintenance

* Cordiale is a native Rust and Slint desktop app. It has no embedded browser engine. It supports Windows x64 and ARM64, macOS Intel and Apple Silicon, and Linux packages for Debian 13, Ubuntu 26.04, AlmaLinux 10 and Arch Linux.
* The interface is translated into German, Spanish, French and Italian. Windows builds use the GUI subsystem and do not open an extra console window.
* Linux packages declare their runtime dependencies. CI builds and checks Linux, Windows and macOS targets. CodeQL checks Rust and GitHub Actions. The build updates dependencies, runs the audit first and removes Slint build warnings.
* The UI code is split into smaller modules for chat frames, slash commands, administration, history, channels, direct messages, callbacks and worker commands. Tests live outside the main UI entry point.
* Cordiale improves text contrast for muted text, timestamps, labels and error messages. The target contrast is WCAG AA 4.5:1.

## Known limits

* USB security-key support through `ctap-hid` is not enabled in release packages for Linux or macOS. It needs a separate CI build and hardware testing.
* Passkey, TOTP, session-share and newer protocol flows have tests with simulated server data. Not every authenticator and Grappa deployment has been tested in a live session.
* Client-token management and account deletion are available in Cicchetto, not Cordiale. File drag and drop is not available on Wayland. The unread badge in the Windows taskbar is available on Windows only.
* See the [README](https://github.com/Sythos/Cordiale#known-gaps) for other known gaps and platform limits.
