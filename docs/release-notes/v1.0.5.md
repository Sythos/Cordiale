# Cordiale 1.0.5

This release improves topic links, text order, read state and direct queries. It also fixes action message display and button sizes. It updates a Rust dependency to fix a security advisory.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* Users can open or focus a direct query when they click a nickname. Cordiale uses the same network and window as the chat.
* Users can open valid topic links in chat and in the Channels list. Links support mouse, keyboard and screen reader use.

### Fixes

* The program removes CTCP ACTION markers from displayed /me messages. It keeps plain text, whitespace, Unicode and mIRC formatting.
* Topic text keeps its spaces, link targets and right-to-left order in Hebrew and Arabic. Topic links remain separate from channel row actions.
* Settings, Radio and media viewer buttons keep a fixed height in tall windows.
* Unread state clears only when the active chat is visible and at the latest row. The program keeps read state separate for each channel, query and network. A locked E2E window does not change the server read cursor. The program keeps a sent message in view after the layout changes.
* Update pulldown-cmark to 0.13.6 to fix RUSTSEC-2026-0433.
* The topic test sets focus on each link before it checks Enter and Space. This keeps keyboard tests stable across platforms.

### Tests

* New tests check CTCP ACTION framing, topic links, link focus, spaces, Unicode, RTL text, wrapping and channel row hit areas.
* New tests check when unread state clears and how the program follows a sent message.
