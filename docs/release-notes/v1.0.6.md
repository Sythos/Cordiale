# Cordiale 1.0.6

This release adds E2E consent and support for Grappa events in protocol versions 52, 53 and 54. It also adds a read-only chat copy view, restores nickname menus, and updates two Rust dependencies.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* Users can select Actions → Copy text to view and copy loaded chat messages. The view shows timestamps and nicknames. It removes mIRC formatting codes and keeps Unicode, spaces, literal markup and URLs. It does not load more history.
* Users can start a new encrypted direct chat after they accept the E2E consent request. Cordiale keeps the encrypted query in a separate window from the plain query. Opening a plain query does not start E2E. An existing encrypted chat does not send another request.

### Fixes

* Right-clicking a nickname in the chat or member list opens its context menu. Left-clicking a nickname still opens a query.
* Cordiale handles unreadable-message NACK events from protocol 52 and `no_such_nick` events from protocol 54.
* Cordiale handles unavailable system information from `sysinfo` 0.40. The rest of the report remains available.

### Dependency updates

* Update `encoding_rs` to 0.8.44.
* Update `sysinfo` to 0.40.1.

### Documentation and tests

* New tests check the copy view, loaded message text, read-only controls, clipboard copy, Escape, and view cleanup.
* New tests check E2E consent, plain and encrypted query separation, existing encrypted chats, unreadable messages, and missing nick events.
* New tests check right-click menus for chat and member-list nicknames. Left-click tests check that query behavior stays in place.
