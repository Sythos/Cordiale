# Cordiale 1.0.20

This release adds optional hardware video decoding, date separators in the channel transcript and a startup splash screen. It also restores the client window state and fixes the layout of the sidebar and the bottom rows.

Package version: `${PACKAGE_VERSION}`. Tag version: `${VERSION}`. GitHub Actions run: `${BUILD_ID}`. Attempt: `${BUILD_ATTEMPT}`.

## Choose one package for your system

* **Windows:** x64 or ARM64 installer and portable archive.
* **macOS:** Intel or Apple Silicon disk image and portable archive.
* **Linux:** Debian 13, Ubuntu 26.04, AlmaLinux 10, Arch Linux, or a portable archive. Linux packages are available for x86_64 and ARM64 where supported.
* **Source:** source archive.

The release includes SHA256 checksum files. The build workflow also creates provenance attestations. See the [installation guide](https://github.com/Sythos/Cordiale/blob/main/docs/installation.md) for package names, dependencies and install steps.

All packages are unsigned. Cordiale does not use a code-signing certificate. Windows SmartScreen and some Linux package managers can show a warning. This is expected for an unsigned community build. It does not mean that someone changed the package.

## Complete change summary

### New features

* The channel transcript shows date separator rows between days.
* The video player can use hardware decoding. It uses software decoding when the hardware decoder fails.
* The Windows x64, Windows ARM64 and macOS packages include hardware decoding.
* The client restores the window state after a restart.
* The startup splash screen shows the logo, which is embedded in the binary.
* The splash screen hands off only when the startup is ready. The launch sign-in starts at that time.
* The Sythos website link in the credits is clickable.
* The player measures audio under-runs and late video frames.

### Fixes

* The Channels button and the channel row align.
* The compose row and the Actions row at the bottom have the same height and stay at the bottom.
* The sidebar [X] buttons end on one right edge.
* The audio worker keeps the first decoded audio packet.
* The hardware decoder keeps queued pictures when it falls back to software decoding.
* The hardware decoder receives the AV1 configuration OBUs.
* The mention rows and the locked-view rows count the date separator rows.
* The program fixes clippy lints and the problems found in review.
* The session and the current screen stay in place when the state is restored.

### Dependencies

* Updated: the dependency files for hardware video decoding.
* Added: the static FFmpeg feature for macOS hardware decoding.

### Tests

* The tests cover the compose row and the Actions row height and position.
* The tests cover the splash screen hand-off.
* The tests cover the sidebar layout and the anchor position.

### Documentation

* The documentation describes playback measurements and platform checks.
* The documentation describes the tester builds, the release gate and the results log.
* The documentation describes the field test steps for hardware decoding.
* A manual check list covers the compose row and the Actions row.
