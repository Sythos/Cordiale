# Provenance of the emoji font

This file is for verification only. The program does not show it.

| File | Source | Licence | SHA-256 |
|---|---|---|---|
| `OpenMoji-black-glyf.ttf` | https://raw.githubusercontent.com/hfg-gmuend/openmoji/master/font/OpenMoji-black-glyf/OpenMoji-black-glyf.ttf | Creative Commons Attribution-ShareAlike 4.0 (`LICENSE-OpenMoji.txt`) | `b0c48711651c0502956692beb2e130ae2fc9b0df3b01febf758b3aeb41501dc4` |

Author: OpenMoji (https://openmoji.org). The file is the original download,
without change. It is a monochrome font. The character map of the file holds
U+1FAEB and U+1FADD.

The program uses the font as the last fallback, after the theme font and
after the system fonts. The font file stays a separate file under the same
licence. The licence text is in `LICENSE-OpenMoji.txt`.

Another font was checked first: Noto Emoji (OFL) stops at about Unicode 15
and has neither code point.
